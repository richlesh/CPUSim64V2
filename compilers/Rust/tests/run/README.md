# tests/run: end-to-end programs for the Rust translator

Each `NAME.rs` is translated to C, compiled by the C11 compiler, assembled and run on
CPUSim64 by `tests/run_tests.sh`. The program's stdout must equal `NAME.expected`.
Optional files next to it:

| File | Meaning |
|---|---|
| `NAME.exit` | expected exit status (absent means 0) |
| `NAME.stderr` | one line that stderr must contain (panic message) |
| `NAME.stdin` | standard input |
| `NAME.argv` | command line arguments |

The expected files are generated by the host `rustc` (debug build, so overflow checks
panic) with `tests/gen_expected.sh NAME...` (no arguments: every test). Run it from
anywhere; it compiles `run/NAME.rs` from the `tests/` directory, so panic locations
read `run/NAME.rs:L:C`. It writes `.expected`, `.exit` for a non-zero status, and
`.stderr` (the message line after `thread 'main' panicked at ...`) for status 101.
Regenerate only after reading the diff of the new output: the host compiler is the
oracle.

The `t*`, `p_*` and `x_*` programs stay inside what `lib/core.rs` provides (no
collections, `Rc`, threads, files, `i128`, `f32`, `async`, `unsafe`); the `s5_*` and
`fe_*` programs exercise the later library files and front-end features. Each program
must pass the front end: `obj/rustc-native --types tests/run/NAME.rs > /dev/null`.

## Tiers

| Prefix | Content |
|---|---|
| `t1_*` | Arithmetic and casts, `let`, `if`, loops and labels, functions and recursion, every `println!` format (`{}` `{:?}` `{:5}` `{:<5}` `{:>8.3}` `{:x}` `{:08b}`, named and positional args), integer and `f64` methods |
| `t2_*` | Structs, impls, enums, `match` (guards, ranges, bindings), `Option` / `Result` and `?`, tuples, arrays, slices and sub-slices, `Box` recursion (expression tree, list, BST), ownership and `Drop` order, modules |
| `t3_*` | `String` / `&str` operations, `Vec` operations, iterator adapters and consumers, sorting (library and hand written), closures (`Fn`, `FnMut`, `FnOnce`, boxed, returned), UTF-8 and chars, a word-frequency program |
| `t4_*` | Traits (default methods, associated consts), generics, `Box<dyn Trait>` and `&dyn Trait`, operator overloading, `Display` / `Debug` impls, `derive(Debug, Clone, PartialEq, PartialOrd, Default, Copy, Eq, Ord)` |
| `t5_*` | Larger programs: bank simulation, RPN evaluator with shunting-yard, tokenizer, matrix multiply and power, prime sieve and factorization, Fibonacci and `checked_*` / `wrapping_*` arithmetic, Unicode string reversal, state machines, Conway's Life |
| `p_*` | Panics: exit status 101 and a `.stderr` message line. Integer overflow (add, sub, mul, neg, `u8`), index out of bounds (Vec, slice), `unwrap` / `expect` on `None` and `Err`, `panic!`, division and remainder by zero, `assert_eq!` with message |
| `x_*` | Process exit and stdin: `std::process::exit(3)` (`.exit`), reading lines with `read_line` (`.stdin`) |
| `s5_core_*` | The Stage 5 `core.rs` additions: `String`/`Vec`/slice methods, iterator adapters, ASCII and number methods, `f64` math, `io::Read`/`BufRead`/`Write`, `write!` to a `String` |
| `s5_col_*` | `lib/collections.rs`: `HashMap` (entry API), `HashSet`, `BTreeMap`/`BTreeSet`, `VecDeque`, `BinaryHeap`, `derive(Hash)` (output never depends on hash order) |
| `s5_rc_*` | `lib/rc.rs`: `Rc`/`Weak`, `Cell`, `RefCell`, trees and graphs, single-threaded `Arc`/`Mutex` |
| `fe_*` | Front-end features: unsizing coercion in constructor arguments, fn item to fn pointer in tuples, const-generic arrays, integer-range `match` |

## Older tests

`hello`, `escapes`, `lex_slice` predate this suite. `gen_expected.sh` with no arguments
regenerates them as well (their output is what the host compiler prints); pass names
explicitly to leave them alone.
